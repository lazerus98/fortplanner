Layout
Tools are on the left rail, the grid fills the middle, and the right panel holds the Z-levels list and the active mode's tokens and properties (collapse it with the chevron at the panel's edge). The search box up top runs any command.

Painting
Left-click paints the active token, right-click erases, drag to paint across cells. Pick a shape in the left rail (Freehand / Rect / Line / Circle / Fill) and set the Brush size there. "Hollow" outlines Rect/Circle.

Mirror
The two mirror toggles in the rail paint symmetrically; drag the amber axis handles on the grid to move the mirror lines.

Modes & tokens
Switch mode with the tabs over the canvas (Dig / Build / Stockpiles / Zones / Burrows), then choose a token and set its properties in the right panel.

Z-levels
Use the Z-levels list in the right panel to switch, add, or remove floors; wheel over the grid to change floor. "Preview" shows the next floor faded for alignment, and #dig designations appear as a teal overlay on other modes.

Blueprints
The tabs in the top bar are your blueprints: click to switch, double-click to rename, and use the +/copy/pencil/trash icons to add, duplicate, rename, or delete.

Command palette
Press Ctrl/Cmd+K (or click the search box) to run anything: undo/redo, selection paste/clear, stamp another blueprint, Trim Z, Clear grid, and the exports.

Selection
The Select tool (top of the rail) marks a rectangle; a floating toolbar offers Rotate / Mirror / Copy / Cut. Paste mode shows a ghost under the cursor; right-click or Esc cancels. "Skip blanks" (in the palette) avoids overwriting non-empty cells.

Import / Export
Use the pill in the canvas's bottom-right corner. Export copies/saves quickfort CSV or a shaded .xlsx (current tab, all tabs, or the whole workbook); Import loads CSV or an .xlsx workbook. Export options (area expansion, bare dig priorities) are in the Export menu.

Keyboard shortcuts
Ctrl/Cmd+K - command palette
Ctrl/Cmd+Z / Ctrl/Cmd+Y (or Ctrl/Cmd+Shift+Z) - undo / redo
Ctrl/Cmd + + / - / 0 - zoom in / out / reset
Ctrl/Cmd+C - copy selection · Ctrl/Cmd+V - toggle paste mode
Esc - clear selection or exit paste mode

Customize colours

These colours drive the grid shading, the legend, and the shaded Excel export. Changes apply live and persist across reloads.
