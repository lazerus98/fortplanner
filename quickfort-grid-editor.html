Build options
Structured fields build {name=..., do_now=true, ...}. name + do_now apply to any building; seasonal_fertilize applies to farm plots (fertilize the plot each season); take_from / give_to / max_general_orders / min_skill / max_skill / labor / labor_mask are workshop/furnace profile props (min_skill/max_skill restrict the skill range of dwarves allowed to work there; labor / labor_mask restrict which labor is enabled at the building). route names a track-stop hauling route (with take_from as the source stockpile) for quantum-stockpile setups; leave it empty to let each apply create a fresh route. config filters which item types a track stop desires, using the stockpile syntax (op-led: -cat_stone/mats/); it is emitted as a :config segment after the {props}, where extra props cannot reach. roller speed sets a roller's push speed (Highest..Lowest; blank = game default). Extra props (track-stop friction, etc.) are appended as-is. Only added when the selected base token has no braces of its own; a hand-typed custom token like trackstopN{friction=500} is left untouched.

Stockpile options
Structured fields build properties like {name=..., barrels=..., links_only=true}. Extra props are appended as-is. The config is appended after properties: a bare preset (seeds, booze) defaults to the = (set) op, or lead with an op yourself to disable (-cat_weapons/mats/) or enable (+steelweapons), chaining segments with commas. Label (type/label) is Quickfort-internal: it keeps two touching same-type piles separate, or merges disconnected regions; use the same label on every tile of one pile.

Zone tokens

Zone options
Location supply targets (only apply to the attached location; blank = game default):
Structured fields build {name=..., location=tavern/mainpub}. allow restricts location access (visitors/residents/citizens/members). Type-specific fields (pond, shoot_from, pets) only apply to the matching zone type. A tomb allows citizens by default; "no citizens" emits citizens=false to disallow them. A gather zone picks trees, shrubs, and fallen fruit by default; the three "no ..." boxes emit pick_trees=false / pick_shrubs=false / gather_fallen=false to turn one off. Location supply targets emit desired_* stock levels for the attached location (tavern goblets/instruments, hospital splints/thread/cloth/crutches/powder/buckets/soap, library paper, temple instruments). Overlapping zones stack a second zone (with its own {props}) on the same tiles: the field is concatenated after this zone's token and before the extent, so this + "t{active=false}" paints n{...}t{active=false}. Extent (WxH) stamps one painted cell so Quickfort expands it into a WxH zone block on import. Extra props appended as-is. Label (type/label) is Quickfort-internal: keeps two touching same-type zones separate, or merges disconnected regions; use the same label on every tile.

Burrow tokens

Burrow options
Structured fields build {name=..., create=true, civalert=true}. civalert registers the burrow with gui/civ-alert (it takes no name). Extent (WxH) stamps one painted cell so Quickfort expands it into a WxH burrow block on import. Extra props support autochop_* and others.

Customize colours

These colours drive the grid shading, the legend, and the shaded Excel export. Changes apply live and persist across reloads.

CSV preview

Exactly what "Download CSV" / "Copy to clipboard" produces for the current tab, with the active export options and modeline markers applied. Read-only.

Tile counts

How many of each tile/building the current tab uses, summed across every Z-level. Each grid cell counts as one tile (tokens with the same base type are grouped; properties and labels are ignored). With an active selection you can scope the tally to just that region (handy for sizing one room before tiling it out).

Find & replace tokens

Replace every cell whose token exactly matches "Find" with the "Replace" token, on the current tab. Matching is exact (properties and labels included),use the eyedropper (Alt+click) or the legend to grab the precise token. Leave "Replace" empty to erase matches. Scope defaults to the current Z-level (one undo step); tick "All Z-levels" to sweep every floor of this tab (each floor is its own undo step, so it takes one Ctrl+Z per affected floor to fully revert).
